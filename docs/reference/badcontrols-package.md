# badcontrols: Difference-in-Differences with Bad Controls

Implements methods for difference-in-differences with bad controls,
i.e., time-varying covariates that are affected by the treatment.
Provides imputation, doubly robust, and machine learning estimators that
are based on Caetano, Callaway, Payne, and Sant'Anna (2026)
[doi:10.48550/arXiv.2608.03881](https://doi.org/10.48550/arXiv.2608.03881)
.
